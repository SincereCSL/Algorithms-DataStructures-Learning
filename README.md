## 数据结构基础
- 数据结构研究的是数据如何在计算机中进行组织和存储，使得我们可以【高效】的获取数据或修改数据。

* 数据结构应用场景
    * 数据库：
      * 树结构： AVL、红黑树、B类树、哈希表
    * 操作系统
      * 优先队列
      * 内存管理：内存堆栈
      * 文件管理
    * 文件压缩：压缩算法(哈夫曼树)
    * 寻路算法：
      * 图论算法： 
        * DFS(深度优先遍历): 使用栈
        * BFS(广度优先遍历 ): 使用队列
